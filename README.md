# Commix-Automation-Bash-Script
# ⚙️ 🧪 What This Script Does

This script combines **many advanced Commix features**:

✔ Target URL input
✔ Parameter targeting (`-p`)
✔ POST data testing
✔ Cookie injection
✔ Proxy support (Burp)
✔ Header testing (User-Agent)
✔ OS fingerprinting
✔ Crawling (`--crawl=2`)
✔ Tamper bypass (`space2ifs`)
✔ Batch mode (no prompts)
✔ Multi-target scanning (`-m file.txt`)
✔ Organized output directory

---

# 🚀 How to Use

### 1. Save script

```bash
nano commix_auto.sh
```

### 2. Paste code → Save

### 3. Make executable

```bash
chmod +x commix_auto.sh
```

### 4. Run it

```bash
./commix_auto.sh
```
